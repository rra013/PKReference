Part 7. The API

All read-only except the token request. JSON, cached for 15 minutes, with weak ETags on /v1. With the server running, Swagger UI at /swagger-ui.html documents every field.

RequestController methodReturns

Status codes. 200 with a body; 304 when If-None-Match matches; 400 for a bad parameter (IllegalArgumentException); 401 with a code field when signing in fails; 404 for something not stored (NoSuchElementException).

Windows. window=14d, 30d (the default) or regulation (every stored event of the format).
