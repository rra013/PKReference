9.2 Golden files

The app repeats three of the server's computations on the device, for when there is no server. To keep the two from drifting, both test suites check the same recorded files under src/test/resources/golden:

  • species-identity.json: how team members' names become species keys (SpeciesVocabularyGoldenTest).
  • meta-fixture.json: the insights for the fixture event (MetaGoldenFileTest).
  • ladder-fixture.json: the ladder fixture reduced (LadderGoldenFileTest).

A change on either side fails a test until the other side matches.

9.3 Techniques worth naming

  • Injected clocks. Time-dependent code takes a Clock; tests pass a fixed or movable one (RequestThrottleTest.FakeClock, TokenServiceTest.TestClock).
  • Mocking the edge only. LimitlessClient and SmogonClient are mocked; everything between them and the database is real in the pipeline tests.
  • A real server for path tricks. ApiAuthTomcatTest starts Tomcat and sends raw requests over a socket, because MockMvc doesn't normalize paths the way a server does.
  • Awaitility. Pipeline tests wait for an asynchronous result with await().untilAsserted(...) instead of sleeping.
